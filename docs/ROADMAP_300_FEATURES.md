# Roadmap 300+ Features

The 300+ product map is generated from 30 categories in the feature registry.

Priority lanes:

1. AI Chat and streaming reliability
2. Photo generation and gallery
3. Canvas project generation
4. Website, landing and dashboard generators
5. Malik Codex 1.0
6. Billing, teams, analytics and admin
7. Marketplace, integrations, automation and deploy tools

Each feature must connect:

- UI button or panel
- Action handler
- Route or modal
- Backend hook or safe fallback
- Loading, success and error state
