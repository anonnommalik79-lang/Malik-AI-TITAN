# MalikLLM MAX — final router integration

Final main-branch marker for the 2026-09-21 model-router release.

- MalikLLM MAX is the automatic default model.
- xKiro, LLM7 and NaraRouter catalogues are integrated.
- 138 verified catalogue entries are registered across text, image and video.
- Original provider/model names and provider branding are used in public catalogues.
- Existing Malik AI routes remain available as internal fallbacks.
- Free/automatic routing is separated from catalog-only/PAYG routes.
- Catalog-only routes are not spent automatically.
- Render deployment is intentionally not triggered by this commit.
