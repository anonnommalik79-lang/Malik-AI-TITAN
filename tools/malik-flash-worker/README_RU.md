# MALIKII Flash Chrome Worker

Экспериментальный независимый сервис. На 14 ноября 2026 года Google AI Mode перенаправляет на `/search?udm=50`, а Google ограничивает автоматический доступ к этому маршруту. Воркер проверяет `robots.txt` перед запуском Chrome и возвращает `GOOGLE_AUTOMATION_RESTRICTED` при запрете. См. [проверку релиза](../../docs/malikllm-flash/BROWSER_WORKER_ROLLOUT.md).

## Локальные проверки

```sh
npm ci
npm test
```

Воркер требует Node.js 22+ и установленный Chrome или Chromium с работающей песочницей. Конфигурация:

| Переменная | Назначение |
|---|---|
| `MALIK_FLASH_WORKER_SECRET` | Случайный серверный секрет, минимум 24 символа. |
| `MALIK_FLASH_WORKER_BIND` | По умолчанию `127.0.0.1`. |
| `MALIK_FLASH_WORKER_PORT` | По умолчанию `8793`, поддерживается `PORT`. |
| `MALIK_FLASH_ALLOW_REMOTE` | Для удалённого подключения нужен защищённый HTTPS-прокси, который сам выставляет `X-Forwarded-Proto` и закрывает прямой доступ к порту. |
| `MALIK_FLASH_PROFILE_DIR` | Отдельный закрытый каталог профилей с правами `0700` на зашифрованном диске. |
| `MALIK_FLASH_CHROME_PATH` | Путь до локально установленного Chrome или Chromium. |
| `MALIK_FLASH_HEADLESS` | По умолчанию `1`. Значение `0` запускает видимое окно. |

Оба маршрута `GET /health` и `POST /v1/ask` требуют bearer-авторизации. `/health` сообщает о доступности локального браузера и политике доступа, отдельная проверка входа выполняется для каждого профиля. Для получения готового ответа предусмотрена проверка завершения и уникальный идентификатор запроса. Google-аккаунты никогда не передаются через HTTP-эндпоинты воркера.

Публичного входа в Google в этом воркере пока нет. До получения разрешения на browser-интеграцию, безопасного процесса подтверждения отдельных аккаунтов и live-проверок держите `MALIK_FLASH_ISOLATED_WORKER=0`.
