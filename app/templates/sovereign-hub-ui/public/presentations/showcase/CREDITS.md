# Showcase photos

Sample pictures for the example slides on the presentation studio's start
screen (desktop). They come from Start Bootstrap's open-source templates,
MIT licensed, which ship free stock photography:

- `strategy.webp` — startbootstrap-creative, `src/assets/img/bg-masthead.jpg`
- `product.webp` — startbootstrap-landing-page, `src/assets/img/bg-showcase-3.jpg`
- `horizons.webp` — startbootstrap-grayscale, `src/assets/img/bg-masthead.jpg`

Resized to 1100 px and re-encoded as WebP. Source repositories:
https://github.com/StartBootstrap
