## Реальные изменения

`resolveDomainPlan` строит единый ограниченный план: цель, несколько областей, контекст продолжения, требуемая доставка, существующие инструменты, классы доказательств, необходимость визуалов и формат. Предмет обсуждения отделён от выполняемого действия: обзор сайта, промпт для картинки и научное объяснение не запускают соответствующие генераторы.

План используется в реальном POST маршрутизаторе, координаторе MAX/других выбранных текстовых моделей, web policy, кодовом/мультимодальном контрактах и подборе изображений. Новая текстовая задача сбрасывает устаревшие флаги проекта; правка активного проекта сохраняется. Существующие генераторы, калькуляторы, документные экспортёры, проверки точности и streaming сохранены.

Для смешанных/неопределённых текстовых задач координатор может один раз запросить семантическую классификацию **выбранной моделью**. Области имеют открытый словарь, а не единственную закрытую категорию. JSON проверяется; предложение модели может включить реальный read-only поиск, но не разрешает записи, приватные подключения или генерацию медиа без соответствующего запроса. Обязательный поиск и явные запреты не отменяются модельным предложением.

Ограничения дополнительного разбора: один вызов, до 320 выходных токенов, целевой таймаут 1800 мс (таймер может задерживаться при перегрузке event loop), без повторов. 320 токенов резервируются из бюджета итогового ответа; при малом оставшемся лимите разбор пропускается. Ошибка/невалидный JSON/таймаут возвращают локальный план; отмена пользователя распространяется дальше. Простые запросы обходятся без этого вызова. Ключи, постоянное хранение и новые провайдеры не добавлялись.

Визуальный контекст сохраняется в фотоподсказках, секциях ответа, карточках, Commons/Wikipedia, платных резервных провайдерах, Unsplash и клиентском/server cache key. Проверяются тип объекта, явно заданная эпоха (включая BCE), известная синтетическая природа изображения. При недостаточной метаинформации допустимо не показать картинку. Точный энциклопедический объект приоритетнее лексического тёзки. «Только текст», JSON, расчёт, перевод и обычный разговор не получают декоративных фото.

Компоновка, CSS, навигация, кнопки и размеры не менялись. В двух TSX-файлах передаётся контекст; React provider не создаёт DOM-обёртки. Проверены стабильность контекста/зависимостей эффектов и сохранение очистки подписок по React-навыку.

## Команды публикации — только после отдельного разрешения

В корне репозитория, из текущей ветки. Сначала проверьте, что diff содержит только перечисленную работу. Выполнять каждую следующую команду только после успешной предыдущей. При конфликте merge остановиться; force push не использовать.

```powershell
git diff --check
git add -- app/templates/sovereign-hub-ui
git diff --cached --stat
git commit -m "feat(ai): add universal contextual domain intelligence"
git fetch origin main
git merge --no-edit origin/main
git push origin HEAD:main
```

Последняя команда обновляет удалённую `main` из проверенной ветки, сохраняя параллельные изменения через merge. Эти команды в рамках текущей задачи **не запускались** (кроме read-only проверок diff/fetch ранее).
